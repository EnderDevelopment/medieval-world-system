# Medieval World System

A medieval-themed world with quests, shops, upgrades, and custom mobs.

## Features

- Medieval-themed world with custom elements
- Story mode with quests and side quests
- Shops for buying items
- Upgrades for items
- Custom mobs and bosses

## Requirements

- FiveM server
- ESX Framework

## Installation

1. Download the script
2. Place the script in your FiveM server's resources folder
3. Add `start MedievalWorldSystem` to your server.cfg file

## Usage

### Commands

| Command | Description |
|---------|-------------|
| /startquest <questName> | Start a quest |
| /completequest <questName> | Complete a quest |
| /buyitem <shopName> <itemName> | Buy an item from a shop |
| /upgradeitem <itemName> | Upgrade an item |
| /spawnmob <mobName> | Spawn a mob |
| /spawnboss <bossName> | Spawn a boss |
| /spawnplayer <spawnName> | Spawn a player |

### Configuration

Edit the `config.lua` file to customize the world settings, quests, shops, upgrades, mobs, and spawns.
